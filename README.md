# Thanusha's Portfolio

Responsive dark-themed portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and current year
- `assets/portfolio-collage.png` — apartment app screenshot collage (included)
- `assets/women-safety-app.png` — SubadrNari screenshot (included)

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your email.
2. Replace `91YOURNUMBER` with your WhatsApp number including country code (digits only).
3. Replace the `href="#"` links on `apartmentDemoLink` and `safetyDemoLink` with public demo URLs, if deployed.
4. Verify all listed features are implemented and working.
5. Use fictional data and demo contacts in public screenshots. Never publish resident data, real emergency contacts, private location history, credentials or secret keys.

## Preview
Open `index.html` in a browser. No build step is required. Google Fonts require internet; the page still works without them.

## Publish
Publish the folder as a static site using GitHub Pages or another static hosting provider. Never upload `.env` files, private databases, passwords or secret keys.
